# 전자기록 결재과정 복원 · 통합 뷰어

대통령기록 장기보존포맷(v1.1) XML을 기반으로, 전자기록 6건의 결재·처리 과정과 원문 첨부파일을 하나의 웹 페이지로 복원한 뷰어입니다.

수록 기록:
1. **지시사항관리카드** — 「06년 하반기부터 기록관리 이관작업을 추진할 것」 (지시→이행경로→추진실적·일지 21건)
2. **일지** — 기록관리시스템 소유권 이관 및 현장실사 방문
3. **일지** — 대통령권한대행 기록이관을 위한 기초조사
4. **일지** — 이관 대상 업무매뉴얼 정리
5. **일지** — 대통령상징물 이관계획수립을 위한 기초 자료 수집 (김대중 대통령 행정박물)
6. **문서관리카드** — 대통령 지시사항 추진실적 이관 협조요청 (국가균형발전위원회, 결재선 6 · 참조 7 · 공람 49)

## 구조

```
index.html          뷰어 (첨부는 base64로 넣지 않고 files/ 를 참조)
files/rec1..rec4/   각 기록건의 원본 XML + 첨부파일(HWP/PDF/XLS)
.nojekyll           GitHub Pages가 파일을 그대로 서빙하도록 하는 표식
```

## GitHub Pages로 발행하기

1. 새 리포지토리를 만들고 이 폴더의 내용을 그대로 커밋·푸시합니다.
   ```bash
   git init
   git add .
   git commit -m "전자기록 결재과정 복원 뷰어"
   git branch -M main
   git remote add origin https://github.com/<사용자>/<저장소>.git
   git push -u origin main
   ```
2. 리포지토리 **Settings ▸ Pages** 에서 Source를 `main` 브랜치 / `/ (root)` 로 지정합니다.
3. 잠시 후 `https://<사용자>.github.io/<저장소>/` 에서 열립니다.

> 로컬 확인: `python3 -m http.server` 실행 후 `http://localhost:8000` 접속.
> (원본 XML 미리보기는 `fetch`를 쓰므로 `file://` 직접 열기가 아니라 http 서버로 확인해야 합니다.)

## 참고

- 파일당 용량은 최대 8.8MB로 GitHub 제한(파일당 100MB, 50MB 경고) 이하이며, 사이트 총합은 약 24MB입니다.
- 이 기록들은 XML 메타데이터상 공개유형이 **비공개**로 표기되어 있습니다. 공개 웹에 게시하기 전, 해당 기록이 공개(공개재분류) 처리된 기록인지 반드시 확인하시기 바랍니다.
